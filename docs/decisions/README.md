# Decisions

Dated records of a choice and why, for anything future work would otherwise have to
re-derive from git log archaeology. Not a running log of every change - most commits need
nothing more than their own message.

- File as `YYYY-MM-DD-short-title.md`.
- A record is a snapshot: write it, don't edit it later. If the decision changes, write a
  new record - the old one stays, because the reasoning it captured is still real history.
- Keep it short. This repo is small; a decision record here is a paragraph or two, not a
  design doc.

Empty until something needs one. That's expected, not a gap.
